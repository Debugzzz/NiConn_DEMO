## 已完成（随 v0.1.0 / v0.1.1 发布）

- **连接**：STA 模式三步引导、自动配对码确认、最近相机保存与快速重连
- **实时取景**：MJPEG 无线取景（约 10fps，可调）、点按对焦（单点 AF 区域 + 绿框）、快门拍摄、ISO / 快门速度 / 光圈调节、横屏模式
- **相册**：缩略图网格（NEF/JPEG 角标）、大图查看（EXIF 旋转、双指缩放）、照片信息、删除、长按多选批量下载
- **界面**：iOS 设计系统——系统色板、大标题、分组卡片、iOS 风格弹窗、Tab Bar（v0.1.1）
- **工程**：CI 打 tag 自动构建 APK 并发布 Release；JVM 单元测试（含 Mock 相机服务器）

## 已完成、待真机验收（本地提交，未推送）

1. **设置抽屉**：点击连接页「NiConn」标题从左侧滑出（75% 宽）
   - 取景帧率（省电/均衡/流畅，运行中生效）、默认横屏、屏幕常亮、相册缩略图列数
   - 关于：版本、GitHub 仓库、许可证
2. **曝光补偿（0x5010）与白平衡（0x5005）**：取景页第二行控件，档位/枚举从相机查询
3. **横屏取景布局修复**：统一两行布局，横屏时各控件原地旋转（快门键此前被挤出屏幕）
4. **相册文件名解析修复**：按 PTP 规范解析长度前缀字符串（真机格式），保留裸空终止扫描作回退
   （Mock 兼容）。此前症状：文件名乱码/缺字符 → `IMG_编号` 兜底。单元测试覆盖规范格式、
   中文名、遗留格式
5. **应用内日志**：`AppLog` 环形缓冲（2000 条），记录会话生命周期与取景帧调试信息；
   设置 → 诊断 → 导出日志（系统分享面板）/ 清空日志

## 已知问题

- **取景点按对焦坐标未校准**：换算用固定 8 倍系数，点按位置与实际对焦点有偏差，
  其他机身需要重新标定（校准向导见规划）

## 近期规划（优先级从高到低）

1. **断线自动重连**：相机休眠 / 热点波动 / 锁屏返回后自动重建会话（保存地址直连，
   失败再发现），期间 UI 显示「重连中」而非报错 —— 设计文档 Phase 4 核心
2. **取景页状态信息**：电池电量（0x5001）、剩余可拍张数、对焦模式，经
   `GetDevicePropValue` / `GetEventEx`（0x941C）轮询显示在取景画面角落
3. **对焦校准向导**：设置内引导点四个角 → 相机反馈实际对焦点 → 拟合缩放系数存档，
   支持多机身
4. **深色模式**（可选）：设置项「跟随系统/浅色/深色」，需补深色色板

## 远期方向

- 远程变焦取景（`LiveViewZoomArea` 0xD1BD，规范支持）
- 录像控制（StartMovieRecInMedia 等）、间隔拍摄
- AP 模式连接（相机作热点）、多机群控
- 协议日志持久化与自动附加到错误报告
